# 공수1 유형 체계 초안 (2026-05-07)

문제은행 6,000+ 문항을 분석해 도출한 1차 유형 체계. 사용자가 검수·수정 후 확정하면 LLM 자동 라벨링에 사용.

기준: **"학생이 풀이 시작 시 동일한 출발점을 잡는다"** — 같은 유형 = 같은 첫 수, 같은 풀이 전략.

---

## 1. 다항식의 연산 (8유형)

| # | 유형명 | 핵심 패턴 |
|---|--------|----------|
| 1.1 | 다항식 사칙연산 | 두 다항식 $A, B$의 $A+B$, $A-B$, $AB$ 계산 |
| 1.2 | 다항식 나눗셈 (직접/조립제법) | $A$를 $B$로 나눈 몫·나머지 |
| 1.3 | 곱셈공식 — 식의 값 | $a+b, ab$ 주어졌을 때 $a^2+b^2$, $a^3+b^3$ 등 |
| 1.4 | 곱셈공식 — 전개식의 계수 | $(x+a)^n$ 등에서 특정 항 계수 |
| 1.5 | 항등식 — 계수 비교 | $x$에 관계없이 성립 → 계수 비교 |
| 1.6 | 내림차순/오름차순 정리 | 다변수 다항식 정리 후 계수 |
| 1.7 | 다항식 활용 — 도형 | 직육면체·삼각형·반원 넓이/부피 |
| 1.8 | 다항식 활용 — 실생활 | 기계 처리량, 가격 등 일상 모델링 |

## 2. 항등식과 나머지정리 (7유형)

| # | 유형명 | 핵심 패턴 |
|---|--------|----------|
| 2.1 | 항등식 — 계수 비교 / 수치 대입 | $f(x) = ax^2+bx+c$ 항등식 → $a,b,c$ |
| 2.2 | 나머지정리 — 일차식 1개 | $f(x) ÷ (x-k)$의 나머지 |
| 2.3 | 나머지정리 — 이차식으로 나눔 | 두 일차식 나머지 → 이차나머지 결정 |
| 2.4 | 인수정리 — 나누어떨어짐 조건 | $f(\alpha)=0$ → 미지수 결정 |
| 2.5 | 조립제법 활용 | 빈칸 채우기, 몫·나머지 결정 |
| 2.6 | 조건부 종합형 (가/나/다) | 다중 조건 만족 다항식 결정 |
| 2.7 | 두 다항식 동시 만족 | $f(x), g(x)$ 양쪽 조건 |

## 3. 인수분해 (7유형)

| # | 유형명 | 핵심 패턴 |
|---|--------|----------|
| 3.1 | 공식 직접 적용 | $a^2-b^2$, $a^3 \pm b^3$, 완전제곱 |
| 3.2 | 공통인수 / 치환 | 묶기 또는 $X = x^2+x$ 등 치환 |
| 3.3 | 복이차식 | $x^4 + ax^2 + b$ |
| 3.4 | 인수정리 + 조립제법 | $f(\alpha)=0$ 찾고 인수분해 |
| 3.5 | 두 일차식 곱 조건 | "두 일차식 곱으로 인수분해되도록" 미지수 |
| 3.6 | 인수분해 활용 — 큰 수 계산 | $99^3 + 1$ 같은 수치 계산 |
| 3.7 | 인수분해 활용 — 도형/삼각형 | 변 길이 관계로 삼각형 판정 |

## 4. 복소수 (7유형)

| # | 유형명 | 핵심 패턴 |
|---|--------|----------|
| 4.1 | 복소수 사칙연산 | $(a+bi) \pm (c+di)$, 곱셈·나눗셈 |
| 4.2 | 켤레복소수 성질 | $\bar{z}, z+\bar{z}, z\bar{z}$ |
| 4.3 | $i$의 거듭제곱 주기성 | $i^n$ 주기 4 활용한 합 |
| 4.4 | 음수의 제곱근 / 무리수와 허수 | $\sqrt{-a}\sqrt{-b}$ 부호 |
| 4.5 | 복소수가 실수/허수일 조건 | $z$가 실수 ↔ 허수부=0 |
| 4.6 | $a+bi=c+di$ 등식 | 실수부·허수부 비교 |
| 4.7 | 1의 거듭제곱근 ($\omega$) | $x^3=1$ 한 허근 활용 |

## 5. 이차방정식 (8유형)

| # | 유형명 | 핵심 패턴 |
|---|--------|----------|
| 5.1 | 근과 계수의 관계 | 두 근의 합·곱 → 식의 값 |
| 5.2 | 새로운 이차방정식 만들기 | $\alpha, \beta$로 새 두 근 → 새 방정식 |
| 5.3 | 판별식 — 실근/허근/중근 조건 | $D > 0, D = 0, D < 0$ |
| 5.4 | 항상 중근 조건 | "실수 $k$ 값에 관계없이 중근" |
| 5.5 | 한 근이 주어진 경우 | $\alpha = 1+i$ 등 → 미지수 결정 |
| 5.6 | 켤레근 정리 | 한 허근 → 다른 허근은 켤레 |
| 5.7 | 근의 부호 조건 | "두 근이 양수", "한 근만 음수" |
| 5.8 | 활용 — 잘못 본 문제 등 | 학생 A/B가 일부 잘못 봄 시나리오 |

## 6. 이차함수 (10유형)

| # | 유형명 | 핵심 패턴 |
|---|--------|----------|
| 6.1 | 구간 최대·최소 (꼭짓점이 구간 내) | $\alpha \le x \le \beta$ 최대·최소 |
| 6.2 | 구간 최대·최소 (변수 포함) | 구간이 변수 $a$에 의존 |
| 6.3 | 그래프와 $x$축 교점 (실근 조건) | 두 교점, 한 점에서 접, 안 만남 |
| 6.4 | 그래프와 직선 교점/접점 | 접하는 조건, 두 점에서 만남 |
| 6.5 | 이차함수 결정 | 세 점 / 꼭짓점+한 점 / 절편 조건 |
| 6.6 | 두 이차함수 관계 | $f(x) \le g(x)$, 교점 등 |
| 6.7 | 그래프 대칭축 / 평행이동 | 축 $x=k$ 활용 |
| 6.8 | 절댓값 / 합성 그래프 | $y = |f(x)|$, $f(f(x))$ 형태 |
| 6.9 | 활용 — 실생활 최적화 | 가격·판매량, 텐트, 울타리 |
| 6.10 | 활용 — 도형 넓이/부피 최대 | 직사각형 넓이, 사다리꼴 등 |

## 검수 포인트 (사용자에게)

다음 항목을 확인해주세요:

1. **유형 명칭 적절성**: 강의/상담에서 학생에게 그대로 말할 수 있는 단어인가
2. **유형 누락**: 위 표에 없는 빈출 유형 있는가 (특히 학원/내신 특화)
3. **유형 통합/분리 필요**: 너무 세분돼 있거나, 반대로 한 유형으로 묶기 모호한 것
4. **단원 경계 케이스**: 예) "이차방정식의 정수근" — 5번에 둘지 6번 이차함수에 둘지
5. **킬러문항 처리**: 6.10 같은 종합형이 사실 거의 다른 단원 종합인 경우 별도 분류?
